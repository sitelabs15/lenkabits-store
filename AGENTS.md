# Lenkabits Store

Sitio web de Lenkabits Store (Puebla, México): componentes de PC, equipos a
medida, ensamblado y servicio técnico.

## Convenciones

- El proyecto usa TanStack Start con React 19, Vite, Nitro y Tailwind CSS v4.
- Los componentes de tienda viven en `src/components/site/` y los componentes
  base de UI en `src/components/ui/`.
- Los textos visibles para el usuario están en español (es-MX).
- Antes de dar por terminado un cambio, ejecuta `npm run lint` y `npm run test`.
